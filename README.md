# Матрица Судьбы · site3

![Обложка проекта](docs/assets/poster.webp)

**Модульная версия калькулятора**

Модульная версия калькулятора site2 с разделением UI на отдельные файлы; расчётные механики сохранены.

**Тип:** Статический сайт · рефакторинг · **Версия:** 1.0.0 · **Документация сверена:** 2026-10-08.

[Версии и скачивание](docs/RELEASES.md) · [Аудит и предложения](docs/AUDIT.md) · [Исходники](https://github.com/kipingame-cell/site3) · [Сборки](https://github.com/kipingame-cell/site3/actions)

## Возможности

- Личный расчёт и совместимость на общем расчётном ядре.
- Модульные компоненты карточек, разделов, здоровья и сохранённых результатов.
- Трактовки по арканам и программам, печать и экспорт.
- Локальный Node.js-сервер без npm-зависимостей.
- Восстановлены 26 отсутствовавших файлов базы из публичного site2.

## Запуск и проверка

```bash
node server.js
# http://localhost:3000
# Проверки в отдельном терминале:
npm test
```

Для обычного запуска таблицы уже находятся в `public/db/`; приватный `site` не нужно публиковать. В исходной версии workflow GitHub Pages отсутствовал; ссылка на опубликованный site3 не считается проверенным рабочим сайтом.

## Проверенное состояние

После публикации всех 26 таблиц GitHub Actions выполнил `npm test`: **23/23 теста прошли**, ошибок нет. Проверки включают расчётное ядро, полный перебор 146 462 дат за 1800–2200 годы и выбор программ. Все восстановленные файлы сверены с источником по Git blob SHA; содержимое совпадает. Публикация на Pages отдельным workflow ещё требует настройки.
