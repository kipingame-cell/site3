# Матрица Судьбы — Android

Автономный APK на базе исправленного модульного калькулятора `site3`. Android 8.0+; пакет `ru.kipin.matrix`, версия 1.0.0. Расчёт, база трактовок, шрифты, PDF и PNG работают без загрузки сайта. Сохранённые даты хранятся локально. Интернет и доступ ко всему хранилищу приложению не требуются.

Встроенный WebView загружает только упакованные ресурсы через локальный HTTPS-origin. Внешние ссылки открываются отдельным браузером. Экспорт PDF использует системный выбор файла; отправка карточки — временное разрешение на чтение одного файла через собственный ContentProvider. Приложения-получатели могут требовать интернет для отправки.

## Сборка

Нужны Java 17 с модулем `jdk.compiler`, Android SDK Platform 35 и Build Tools 35.0.0. Официальные SDK-архивы: `platform-35_r02.zip`, `build-tools_r35_linux.zip` на `https://dl.google.com/android/repository/`; контрольные суммы проверять по `repository2-1.xml`.

```bash
python3 android/build.py --sdk-root /absolute/path/to/android-sdk
```

Скрипт копирует `public/`, подключает Android-адаптер, компилирует Java и ресурсы, подписывает APK, проверяет подпись и zipalign. Результат: `android/dist/Matrix-Sudby-1.0.0.apk`. В `android-build.json` внутри APK записан коммит веб-калькулятора.

Ключ автоматически создаётся в `android/signing/`, резервная копия — `android/dist/Matrix-Sudby-signing-backup.zip`. Каталоги исключены из git. Хранить резервную копию приватно. Для обновлений использовать тот же ключ через `--signing-dir`, повышать versionCode и versionName в AndroidManifest.xml и версию в build.py. Не заменять ключ: иначе Android не установит новую версию поверх старой.

Промежуточные возраста прогнозируются приближённо; исторические трактовки не прошли полную сверку с авторскими материалами. Подробности: `docs/LADINI-CORRECTIONS-2026-10-18.md`.

Отсутствующие в site3 файлы PDF-модуля и шрифтов при сборке загружаются из зафиксированного коммита site2 `9e3c79c`; SHA-256 каждого файла проверяется. В APK они входят полностью, интернет нужен только при первой сборке, не при использовании приложения.
