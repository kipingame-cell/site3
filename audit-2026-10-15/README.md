### SITE3-01 · P1 · Проверка static-root допускает соседнюю папку с тем же префиксом

- Статус: В site3 воспроизведено HTTP 200; в site2 подтверждён идентичный дефект кода.
- Место: `server.js:51`; [открыть файл](https://github.com/kipingame-cell/site3/blob/main/server.js). Номер строки относится к проверенному снимку.
- Проблема и последствия: Путь public-audit-probe проходит startsWith(public). В site3 локальный HTTP-запрос с encoded slash прочитал созданный контрольный файл вне public. GitHub Pages этот Node-сервер не исполняет.
- Исправление: Проверять relative(ROOT,target), запретить .. и абсолютный результат; учитывать symlink. По умолчанию слушать loopback.
- Критерий приёмки: Контрольный файл в соседней public-* возвращает 403; нормальная статика доступна.
